# Content derived from the KiCad libraries

The following files are copies (paths adjusted) of the official KiCad
libraries:

- `src/symbols/passives.kicad_sym` (symbols R, C, C_Polarized, L, FerriteBead
  from `Device.kicad_sym`)
- `footprints/LIB_Passives_SMD.pretty/*` (from `Resistor_SMD`, `Capacitor_SMD`,
  `Inductor_SMD`)
- `3dmodels/LIB_Passives_SMD.3dshapes/*`
